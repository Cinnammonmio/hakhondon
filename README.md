# หาคนโดน

รวม 21 เกมวงเพื่อน ลุ้นว่าใครโดน มีมิมอนเป็นมาสคอต เล่นบนมือถือเครื่องเดียววางกลางวงได้เลย

- **ลุ้นดวง:** จระเข้งับนิ้ว, ระเบิดเวลา, นิ้วใครโดน, ขวดหมุน, เปิดไพ่ตัวซวย, ลูกโป่งสูบลม, กล่องมิมอน, เลขบอมบ์, ไพ่สูงต่ำ, ซูชิวาซาบิ
- **ใช้ฝีมือ:** หยุดที่ 10 วิ, ไวกว่าแสง, จำลำดับสี, เล็งเป้า, เลขเร็ว, คลื่นยึดพื้นที่, ตึกสูง, มิมอนเปลี่ยนสี
- **ยากขึ้น:** สีหลอกตา, หาสีที่ต่าง, เรียงเลข 1–16

จบเกมแล้วสุ่มต่อได้ 2 โหมด คือสุ่มคนรับกรรมตามผังที่นั่ง หรือซูชิวาซาบิ

ทั้งเว็บอยู่ในไฟล์ `index.html` ไฟล์เดียว ไม่ต้อง build เปิดผ่าน GitHub Pages ได้ทันที
บน iPhone เปิดใน Safari แล้วกดแชร์ → เพิ่มไปยังหน้าจอโฮม จะได้แอปเต็มจอพร้อมไอคอน
