# หาคนโดน

รวม 36 เกมวงเพื่อน (โหมดละ 12 เกม) ลุ้นว่าใครโดน มีมิมอนเป็นมาสคอต เล่นบนมือถือเครื่องเดียววางกลางวง หรือเล่นหลายเครื่องผ่านเน็ตก็ได้

เปิดเล่นได้ที่ https://cinnammonmio.github.io/hakhondon/

- **ลุ้นดวง:** จระเข้งับนิ้ว, ระเบิดเวลา, นิ้วใครโดน, ขวดหมุน, เปิดไพ่ตัวซวย, ลูกโป่งสูบลม, กล่องมิมอน, เลขบอมบ์, ไพ่สูงต่ำ, ซูชิวาซาบิ, ตัดสายไฟ, ตู้กาชา
- **ใช้ฝีมือ:** หยุดที่ 10 วิ, ไวกว่าแสง, จำลำดับสี, เล็งเป้า, เลขเร็ว, คลื่นยึดพื้นที่, ตึกสูง, มิมอนเปลี่ยนสี, ทุบมิมอน, วาดวงกลม, เทน้ำ, รัวนิ้ว
- **ยากขึ้น:** สีหลอกตา, หาสีที่ต่าง, เรียงเลข 1–16, จำตำแหน่ง, สลับแก้ว, นับไว, เขียวกด แดงห้าม, บวกต่อเนื่อง, จับคู่ไพ่, ปาเป้า, หลบระเบิด, นิ้วนิ่ง

จบเกมแล้วสุ่มต่อได้ 2 โหมด คือสุ่มคนรับกรรมตามผังที่นั่ง หรือซูชิวาซาบิ

บน iPhone เปิดใน Safari แล้วกดแชร์ → เพิ่มไปยังหน้าจอโฮม จะได้แอปเต็มจอพร้อมไอคอน (ถ้าเคยเพิ่มไว้ก่อนเวอร์ชัน 1.18 ให้ลบแล้วเพิ่มใหม่ เพราะเปลี่ยนแถบสถานะเป็นแบบทึบ)

## เล่นหลายเครื่อง

ใช้ Supabase Realtime (broadcast และ presence) อย่างเดียว ไม่ต้องสร้างตาราง

เว็บนี้ตั้งค่าโปรเจกต์ Supabase ไว้แล้วใน `SB_DEFAULT` ใน `app.html` (ใช้ publishable key ซึ่งเปิดเผยได้) ถ้าจะเปลี่ยนโปรเจกต์ แก้ค่านั้นแล้วรัน `python3 build.py` หรือกรอกในแอปตรง "เล่นหลายเครื่อง → ตั้งค่า Supabase" (เก็บไว้ในเครื่องนั้น)
เครื่องแรกกด "สร้างห้องใหม่" แล้วส่งลิงก์หรือรหัส 4 ตัวให้เพื่อน เครื่องเดียวใส่ชื่อได้หลายคน

ในห้อง หัวห้องเป็นคนเลือกเกม จัดที่นั่ง และกดเล่นอีกรอบ ผลสุ่มตอนจบขึ้นตรงกันทุกเครื่อง

- **กระดานเดียวกันทุกเครื่อง:** จระเข้งับนิ้ว, ระเบิดเวลา, ขวดหมุน, เปิดไพ่ตัวซวย, ลูกโป่งสูบลม, กล่องมิมอน, เลขบอมบ์, ไพ่สูงต่ำ, ซูชิวาซาบิ, ตัดสายไฟ, ตู้กาชา (ตาของใคร คนนั้นกดที่เครื่องตัวเอง)
- **แต่ละเครื่องเล่นคนของตัวเองแล้วเทียบคะแนน:** หยุดที่ 10 วิ, ไวกว่าแสง, เรียงเลข 1–16, ทุบมิมอน, วาดวงกลม, เทน้ำ, รัวนิ้ว, จับคู่ไพ่, ปาเป้า, หลบระเบิด, นิ้วนิ่ง
- **เกมอื่น:** เล่นที่เครื่องหัวห้อง เครื่องอื่นรอดูผล

ทดสอบในเครื่องเดียวได้ด้วย `?net=local` แล้วเปิดหลายแท็บ (ใช้ BroadcastChannel แทน Supabase)
